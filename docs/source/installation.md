# Installation

This section provides instructions on how to install and set up the IggyTop project.

## Prerequisites
- Python 3.11+
- `uv` package manager

## Steps
1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd develop-igT
   ```
3. Install dependencies using `uv`:
   ```bash
   uv sync
   ```
